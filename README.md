# 🚀 My AI Agent Development Journey | GenAI Engineer

Welcome to my **AI Agent Development Journey!**

I am documenting my hands-on learning journey toward becoming an **AI Agent Developer / Generative AI Engineer**. My goal is to understand how LLMs work, build intelligent AI agents, integrate external tools, implement memory, and develop real-world agentic applications.

## 💻 Hands-on Projects

### 1. AI Agent with Python
Building an interactive AI agent using Python and an LLM.

### 2. Tool-Calling AI Agent
Creating custom Python tools and allowing an LLM to select and execute them.

### 3. LangGraph Memory Agent
Implementing conversation memory using checkpointers and thread IDs.

### 4. Databricks Job Monitoring Agent
Building an AI agent that can:
- Check Databricks job execution status.
- Retrieve pipeline failure logs.
- Analyze job failures.
- Suggest corrective actions.
- Request human approval before restarting jobs.

Building an application that retrieves relevant information from enterprise documents and generates contextual answers.
